# Tests and golden vectors

- `golden_vectors/` — generated by `research/reference` (task T1.2): at least 500
  cases covering edge cases and rounding; consumed by both the Rust `arb-math`
  tests and the Python reference (differential, within 1 atom).
- Integration tests live in `programs/arbswap/tests/` (LiteSVM, P2).
- Invariants to encode (Build Plan §10):
  1. For any swap, `out >= min_out` or the swap reverts.
  2. Sell-then-buy the same size never yields more than the start (no free money, up to rounding).
  3. Reserves + liabilities are conserved except for fees and explicit transfers.
  4. `age >= expiry_slots` always rejects swaps.
  5. Out-of-bounds keeper updates always reject.
  6. First-depositor and donation attacks cannot steal funds.
